## Overview

Nivara is a socioeconomic intelligence platform designed to identify economic vulnerability, understand community needs, find opportunity gaps, and connect relevant support.

### Core Workflow

**DATA → PREDICT → UNDERSTAND → MATCH → CONNECT → ACTION**

## What We Built

- ML-based economic-level classification
- Economic Vulnerability Analysis
- Multidimensional socioeconomic analysis
- Employment and skill-gap identification
- Ration demand-pressure analysis
- Government scheme discovery
- RAG-based support retrieval
- CONNECT Engine
- NGO / CSR opportunity matching
- Interactive district-level intelligence

## Technology

- Machine Learning
- Random Forest
- Logistic Regression
- Decision Tree
- RAG
- Socioeconomic Data Analysis
- Interactive Web Application
- Matching / Recommendation Logic
- Google AI Studio
